# Abartılı İş Toplantısı Katılımcı Simülatörü

## Bu Nedir?

Bu proje, dünyanın en gereksiz ama en eğlenceli iş toplantısı simülatörüdür. Toplantılarda insanların söylediği en absürt, en saçma, en "patronu mutlu edecek" cümleleri üretir. Gerçek hayatta bu cümleleri söylerseniz işten atılabilirsiniz. Ama burada güvenlisiniz.

## Nasıl Çalışır?

Python ile yazıldı çünkü Python her şeyi yapar, hatta toplantıları bile. Çalıştırın, rastgele bir katılımcı sözü gelsin. İsterseniz sonsuz döngüde toplantı yapabilirsiniz. Çay demlenene kadar sürebilir.

## Kullanım

```bash
python3 simulator.py
```

## Özellikler

- Gerçekten çalışıyor (inanmazsanız deneyin).
- Abartılı ciddiyetle yazılmış.
- Hiçbir işe yaramaz ama gülmekten ölebilirsiniz.
- Gizli özellikler içerir (bulmaya çalışmayın).
